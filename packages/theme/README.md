# @typomd/theme

Design tokens and light/dark CSS for [typomd](https://github.com/ximing/typomd).

```ts
import '@typomd/theme/default.css' // light; add .typomd-dark on an ancestor for dark
import '@typomd/theme/auto.css'    // prefers-color-scheme
import '@typomd/theme/tokens.json' // JSON map
```

Override any `--typomd-*` variable in your own CSS.
